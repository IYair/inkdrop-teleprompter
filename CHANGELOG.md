# Changelog

## 1.4.0 — 2026-09-15

- Made the top bar the single selector for script profiles.
- Simplified the built-in library to Key points and Clean note.
- Replaced the separate-window symbol with Inkdrop's native window icon.
- Added safe title spacing for native window controls.
- Expanded marker documentation and clarified which profiles can be edited.

## 1.3.0 — 2026-09-15

- Custom profile names and markers can now be edited in place.
- Marker changes are validated against reserved and existing profiles.
- The profile library warns when an edited marker also needs to change in existing notes.
- Removed the persistent language note from the profile-library footer.

## 1.2.0 — 2026-09-14

- Added an in-app profile library for creating and deleting custom script profiles.
- Built-in profiles can be removed from the tab bar and restored later.
- Custom profiles use safe, language-neutral markers and persist locally across Inkdrop windows.
- Deleted custom profiles can be restored immediately with Undo.

## 1.1.0 — 2026-09-14

- New key-points profile with explicit, language-neutral section markers.
- Spanish and English headings, spoken-block labels, and auxiliary sections are recognized automatically.
- Local voice following now selects an on-device Spanish or English recognizer from the chosen content.

## 1.0.0 — 2026-09-12

- First public release.
- Responsive, theme-aware teleprompter in the current or a dedicated window.
- Fixed-speed and local macOS voice-following modes.
- Mirror mode, countdown, progress, font selection, and keyboard controls.
